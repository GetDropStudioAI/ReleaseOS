## What a green run does and does not prove

- It proves that, for the 539 cases, the generated Postgres schema accepts and refuses the same statements with the same message, and that the cascades write the same rows. The cases are SQLite's specification (plan 3.3, layer 1).
- It does **not** prove the same-event firing order for all 117 trigger pairs (plan 3.3 layer 2), the order manifest (layer 3), concurrency (4.8), or TRUNCATE. The cases pin the order only where one statement breaks two rules. Check this when reading the number: reversing the generator's trigger numbering (so the oldest rule fires first) fails 7 cases; ignoring every `WHEN` fails 206.
- The translator is first pass. Constructs it does not know are listed in section 3 and fail visibly instead of being skipped.
